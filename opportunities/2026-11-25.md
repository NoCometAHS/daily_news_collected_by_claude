## 오픈소스 기여 기회

### [Google Summer of Code 2027 준비 — Python 커뮤니티](https://python-gsoc.org/)
> GSoC 2026 사이클은 완료됨. GSoC 2027 기여자 지원은 2027년 3월 예정. 사전 준비를 위해 Python·Django·Jenkins 등 커뮤니티의 `good first issue` 레이블 이슈부터 시작 권장.

### [Outreachy 겨울 코호트 (Dec–Mar)](https://www.outreachy.org)
> 오픈소스 입문자(소외 계층 대상) 인턴십 프로그램. 연 2회 운영 (6~8월 / 12~3월). 현재 겨울 코호트(2026-12 ~ 2027-03) 지원 시기. 공식 사이트에서 최신 모집 일정 확인 필요.

### [KDE / LibreOffice — 초보자 이슈](https://community.kde.org/Get_Involved)
> GSoC 2026 참여 조직 중 초보자 친화적인 프로젝트. KDE는 `junior-jobs` 태그, LibreOffice는 `easy` 태그로 입문 이슈 관리. C++/Qt/Python 경험자에게 적합.

### [Django / CPython — good first issue](https://forum.djangoproject.com/t/gsoc-2026-contributor-looking-to-start-contributing/44422)
> Django와 CPython 모두 GSoC 2026에 참여했으며, 2027 사이클 대비 기여자 사전 참여를 환영. GitHub/GitLab에서 `good first issue` 또는 `beginner-friendly` 레이블로 검색.

### [Jenkins — 초보자 이슈 (Java 개발자)](https://community.jenkins.io/t/gsoc-2026-beginner-java-developer-interested-in-contributing/36380)
> Java 기반 CI/CD 오픈소스 프로젝트 Jenkins. 초보자 대상 `newbie-friendly` 이슈 존재. Jenkins 커뮤니티 포럼에서 멘토와 직접 소통 가능.
