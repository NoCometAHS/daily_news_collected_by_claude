## 무료 강의 / 학습 자료

### [Harvard CS50's Introduction to AI with Python — edX (무료 청강)](https://www.edx.org/learn/artificial-intelligence/harvard-university-cs50-s-introduction-to-artificial-intelligence-with-python)
> 하버드 대학 CS50 시리즈. 탐색·최적화·머신러닝·신경망·자연어처리를 7개 실습 프로젝트로 학습. 강의 자체는 무료, 수료증은 $299. 초급~중급 파이썬 개발자에게 적합.

### [Hugging Face 에이전트 강의 — 무료 수료증 제공](https://huggingface.co/learn/agents-course)
> AI 에이전트 구축 전 과정을 다루는 Hugging Face 공식 강의. LLM·툴 사용·멀티에이전트 시스템까지 커버. 무료 수료 인증서 제공. 현재 AI 에이전트가 주요 트렌드인 만큼 주목도가 높다.

### [Coursera — 무료 AI·ML 강의 모음 (2026)](https://www.coursera.org/courses?query=free&skills=Artificial+Intelligence)
> 구글·DeepLearning.AI·스탠퍼드 등 주요 기관의 AI·ML 강의를 무료로 청강 가능(수료증 유료). 생성형 AI, 프롬프트 엔지니어링, 컴퓨터 비전, NLP 등 다양한 주제 포함. 2026년 최신 업데이트 강의 다수.

### [Kaggle Learn — 실전 ML 마이크로 강의](https://www.kaggle.com/learn)
> Kaggle이 제공하는 무료 마이크로 코스. Python, Pandas, 머신러닝, 딥러닝, NLP, 컴퓨터 비전 등 각 1~4시간 분량. 수료 인증서 무료 발급. 실습 중심으로 초보자도 빠르게 시작 가능.

### [Anthropic Academy — Claude AI 활용 강의](https://www.anthropic.com/learn)
> Anthropic 공식 교육 플랫폼. Claude API 사용법, 프롬프트 엔지니어링, AI 에이전트 구축 등을 다룬다. 수료 인증서 무료 제공. Claude Sonnet 5 등 최신 모델 활용 예제 포함.

## 오픈소스 기여 기회

### [Google Summer of Code 2026 — 진행 중](https://summerofcode.withgoogle.com/)
> GSoC 22주년. 185개 오픈소스 조직이 참여하며 전 세계 기여자를 멘토링. 18세 이상, 오픈소스 경험 2년 미만이라면 지원 가능. 12주+ 코딩·스티펜드 지급. 2026년 3월 지원 마감(현재 기여 기간 진행 중). 참여 조직 목록과 프로젝트 아이디어 확인 가능.

### [Outreachy — 다양성 지원 오픈소스 인턴십](https://www.outreachy.org/)
> 기술 분야 다양성을 지원하는 오픈소스 인턴십 프로그램. 2026년 인턴십 기간: **2026-05-18 ~ 2026-08-17** (현재 진행 중). 다음 라운드 지원은 2026년 말 예정. GSoC 수료자는 지원 불가.

### [Good First Issue — 초보자 친화적 이슈 모음](https://goodfirstissue.dev/)
> `good first issue` 라벨이 붙은 GitHub 이슈를 언어별·프로젝트별로 필터링해 보여주는 사이트. React, Next.js, VS Code, Rust, Flutter, Appwrite 등 인기 프로젝트의 입문 이슈를 손쉽게 탐색 가능. GitHub에서도 `label:"good first issue" language:Python is:open` 형식으로 직접 검색 가능.

### [For Good First Issue — GitHub 공식 오픈소스 기여 가이드](https://forgoodfirstissue.github.com/)
> GitHub이 운영하는 오픈소스 첫 기여 지원 플랫폼. 기여자 역량에 맞는 프로젝트·이슈를 추천하고 기여 가이드를 제공. 2026년 인기 프로젝트로는 Appwrite, VS Code, Flutter 등이 있다.

### [오픈소스 개발자 대회 2026 — NIPA](https://osscontest.kr/)
> 국내 오픈소스 활성화를 위한 정보통신산업진흥원(NIPA) 주관 대회. 오픈소스 프로젝트 개발·기여 부문으로 나뉘며 초보 기여자도 참여 가능. 대회 일정 및 마감일은 공식 사이트에서 확인.
