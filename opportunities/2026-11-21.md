## 무료 강의 / 학습 자료

### [Hugging Face AI Agents 무료 과정](https://huggingface.co/learn)
> 자율학습형 4단계 커리큘럼. AI 에이전트 개발 전반 다룸. 수강 및 인증 모두 무료. 기초 Python 지식 필요.

### [Microsoft AI Agents for Beginners (GitHub)](https://github.com/microsoft/ai-agents-for-beginners)
> Microsoft 공식 오픈소스 강의. 코드 중심 15개 레슨. AI 에이전트 설계·구현·배포까지 단계별로 학습 가능. 무료.

### [Generative AI for Beginners (Microsoft)](https://github.com/microsoft/generative-ai-for-beginners)
> 프롬프트 엔지니어링부터 RAG, AI 에이전트까지 21개 오픈소스 강의. Microsoft 공식 제공, 무료.

### [fast.ai — Practical Deep Learning for Coders](https://course.fast.ai/)
> 실제 코드 작성부터 시작하는 하향식 딥러닝 강의. 첫 번째 수업에서 실제 모델 학습. 약 1년 이상 코딩 경험 권장. 무료.

### [Andrej Karpathy — Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html)
> 역전파 원리부터 GPT 직접 구현까지 약 12시간 분량 영상. 딥러닝 내부 구조를 깊이 이해하려는 개발자에게 추천. YouTube 무료 공개.

### [Kaggle Learn — 머신러닝 마이크로 강의](https://www.kaggle.com/learn)
> 3~5시간짜리 단기 실습 강의. Intro to Machine Learning, Python, Deep Learning 등 다수. 수료증 무료 발급.

### [Google Cloud Skills Boost](https://cloudskillsboost.google/)
> Google Cloud 무료 학습 배지 300개 이상. 생성형 AI 입문 모듈 각 45분 이내. 클라우드·AI 역량 증명에 활용 가능.
