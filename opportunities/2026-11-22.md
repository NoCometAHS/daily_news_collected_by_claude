## 오픈소스 기여 기회

### [Google Summer of Code 2027 — 사전 준비](https://developers.google.com/open-source/gsoc/timeline)
> GSoC 2027 공식 일정 미발표. 2026년 사이클 기준 멘토링 조직 신청은 1월 중순~2월 초 오픈. 참여 프로젝트 탐색 및 기여 이력 쌓기 적기.

### [Apache Airflow — Good First Issues](https://github.com/apache/airflow/contribute)
> 데이터 파이프라인 오케스트레이션 도구. 활발한 기여자 커뮤니티, 초보자 친화 이슈 다수 보유. GitHub `contribute` 탭에서 현재 열린 이슈 확인.

### [LLVM/Clang — Good First Issues](https://github.com/llvm/llvm-project/contribute)
> 컴파일러 인프라 프로젝트. 2026년 8월 기준 초보자 이슈 활발히 등록 중. C++·컴파일러 관심자에게 적합.

### [GitHub Good First Issue 탐색기](https://github.blog/developer-skills/github/browse-good-first-issues-to-start-contributing-to-open-source/)
> GitHub 공식 가이드. `good-first-issue` 라벨이 붙은 이슈를 언어·토픽별로 필터링하여 탐색 가능. [For Good First Issue](https://github.com/github/forgoodfirstissue) 사이트도 함께 활용 권장.
