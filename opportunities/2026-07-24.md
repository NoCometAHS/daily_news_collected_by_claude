## 무료 강의 / 학습 자료

### [Hugging Face LLM Course — 무료 인증서 포함](https://huggingface.co/learn)
> 생성형 AI·LLM 전반을 다루는 공식 무료 강의. 완료 시 무료 인증서 발급. Hugging Face Agents Course도 별도 운영 중(에이전트 AI 전문 과정, 역시 무료 인증).

### [MIT 6.S191 — Introduction to Deep Learning](https://introtodeeplearning.com/)
> MIT가 공개한 딥러닝 입문 강의. 강의 영상·슬라이드·실습 코드 전부 무료 공개. 대학원 수준의 최신 커리큘럼.

### [Anthropic Academy — Claude API 공식 무료 교육](https://www.anthropic.com/learn)
> Claude 및 Anthropic API 활용법을 다루는 공식 무료 교육 플랫폼. 수료 인증서 무료 발급. 에이전트 빌딩, 툴 유즈, 프롬프트 엔지니어링 등 실무 중심.

### [Elements of AI — 완전 무료 AI 입문 코스](https://www.elementsofai.com/kr)
> 핀란드 헬싱키 대학 제공, 비전공자도 쉽게 이수 가능한 AI 입문 MOOC. 전 세계 100만 명 이상 수료. 한국어 지원.

### [fast.ai — 코더를 위한 실전 딥러닝](https://www.fast.ai/)
> 코드 먼저 배우는(top-down) 방식의 무료 딥러닝 강의. PyTorch 기반 실습 중심. 강의 영상·노트북 모두 무료 공개.

### [패스트캠퍼스 AI 바이브코딩 — 내일배움카드 90% 할인](https://fastcampus.co.kr/b2g_kdc_game)
> 2026-07-22 ~ 2026-08-26(5주, 43시간). AI로 나만의 서비스 만들기 실습 과정. 내일배움카드 보유자는 약 32,250원에 수강 가능. **기간: 2026-07-22 ~ 2026-08-26**

## 오픈소스 기여 기회

### [Google Summer of Code 2026 — 진행 중](https://summerofcode.withgoogle.com/)
> 22회째 GSoC. 185개 오픈소스 조직과 1,142명의 컨트리뷰터가 2026-04 선발 완료, 현재 12주 코딩 기간 진행 중. 내년 GSoC 2027 참여를 위해 지금부터 관심 조직 기여 시작 권장. 스티펜드: 중간 규모 약 175시간, 대형 약 350시간 프로젝트.

### [Outreachy — 다음 코호트 신청 대기](https://www.outreachy.org/)
> 다양성 지원 오픈소스 인턴십. 2026년 5월 코호트 종료 후 다음 코호트(통상 12월 시작) 신청은 9~10월 오픈 예정. 스티펜드 $7,000(3개월). 뉴스레터 구독으로 일정 알림 설정 가능.

### [Good First Issue — 입문자 친화 이슈 모음](https://goodfirstissue.dev/)
> 다양한 언어·도메인의 good first issue를 한곳에서 탐색. Kubernetes, Julia, MoveIt(로보틱스), OpenMRS(의료) 등 다양한 프로젝트 수록. 언어/태그별 필터 지원.

### [GitHub good-first-issue 토픽 — 실시간 탐색](https://github.com/topics/good-first-issue)
> GitHub 전체에서 good-first-issue 태그가 붙은 이슈를 실시간으로 탐색. AI·LLM 관련 신규 프로젝트도 다수 포함. 언어별 필터 후 recent 정렬로 최신 이슈 확인 권장.

### [Agenta — LLM 앱 플랫폼 오픈소스 기여자 모집](https://dev.to/mmabrouk/8-beginner-friendly-ai-open-source-projects-to-kickstart-your-career-in-2026-1d45)
> 프로덕션 수준 LLM 앱 빌딩 플랫폼. 백엔드(Python/FastAPI)·프론티어(React/TypeScript) 모두 기여 가능. 문서화된 starter issue와 활발한 멘토링 커뮤니티 운영 중.
