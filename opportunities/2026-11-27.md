## 오픈소스 기여 기회

### [Google Summer of Code (GSoC) 2027 — 사전 준비](https://summerofcode.withgoogle.com/)
> 연례 오픈소스 유급 기여 프로그램. 2026년 기여자 모집은 3월 16~31일에 진행됐으며, 2027년 일정은 아직 미발표. 지금부터 관심 기관의 아이디어 리스트를 모니터링하고 커뮤니티에 참여해두는 것이 유리.

> Python 기반 워크플로 자동화 오픈소스. GitHub contribute 페이지에서 `good first issue` 레이블 이슈 다수 활성 상태. 문서·테스트·버그 수정 등 다양한 기여 경로 존재.

> 범용 컴파일러 인프라 프로젝트. `good first issue` 이슈가 2026년 하반기에도 꾸준히 등록됨. C++·MLIR 관심자에게 적합.

> 초보자 친화 오픈소스 이슈를 언어별·프로젝트별로 필터링해 찾아주는 서비스. Kubernetes·LangChain 등 주요 프로젝트 포함. 현재 활성 이슈는 사이트에서 직접 확인 권장.
