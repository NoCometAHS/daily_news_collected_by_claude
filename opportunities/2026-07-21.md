## 오픈소스 기여 기회

### [GSoC 2026 — Google Summer of Code 현재 진행 중](https://summerofcode.withgoogle.com/)
> 2026년 GSoC는 1,142명의 기여자가 185개 오픈소스 단체와 매칭되어 7~9월 개발 기간 진행 중. AI·보안·머신러닝 분야 확대. 2027년 지원을 노린다면 올해 멘토 단체 목록과 프로젝트 아이디어 문서를 미리 탐색할 것. 스티펜드 $1,500~$6,600 (10~22주).

### [Outreachy 2026-27 Winter — 지원 시작 예정](https://www.outreachy.org/)
> 오픈소스 다양성 증진을 위한 3개월 유급 인턴십($7,000 스티펜드). 겨울 기수 지원은 2026년 9월 마감 예정. 여성, 성소수자, 소수 인종 등 소외 계층 우선 지원. **마감: 2026-09 (예정)**

### [goodfirstissue.dev — 초보자 친화 이슈 큐레이션](https://goodfirstissue.dev/)
> 인기 오픈소스 프로젝트의 `good first issue` 태그 이슈를 언어별·분야별로 필터링해 제공. Python, JavaScript, Go, Rust 등 다양한 언어 지원. 첫 오픈소스 기여를 시작하기에 최적화된 플랫폼.

### [For Good First Issue — GitHub 공익 프로젝트 이슈](https://forgoodfirstissue.github.com/)
> GitHub 공식 운영 사이트. 사회적 가치를 지닌 오픈소스 프로젝트의 접근하기 쉬운 이슈를 큐레이션. 비영리·교육·공공 분야 프로젝트 참여에 관심 있는 개발자에게 적합.

### [오픈소스 기여 가이드 2026 — GitHub (한국어)](https://github.com/freeCodeCamp/how-to-contribute-to-open-source/blob/main/README-KO.md)
> freeCodeCamp가 관리하는 오픈소스 기여 입문 가이드 한국어 버전. 첫 기여 방법, PR 작성법, 커뮤니티 에티켓, 주요 입문 프로젝트 목록 포함. 초보자가 GSoC·Outreachy 준비 전 읽기 좋은 자료.
