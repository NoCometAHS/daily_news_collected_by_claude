## 오픈소스 기여 기회

### [GSoC 2026 — Google Summer of Code (참고: 내년 일정 미리 준비)](https://opensource.googleblog.com/2026/02/introducing-the-185-organizations-for-gsoc-2026.html)
> 2026년 GSoC는 이미 기여자 1,142명 선발 완료(4월 30일 발표). 185개 오픈소스 커뮤니티 참여. 오픈소스 경력 2년 미만·만 18세 이상 대상. 2027년 GSoC를 위해 지금부터 참여 커뮤니티 탐색 추천.

### [Outreachy 2026 — 여름 코호트 진행 중](https://opensource.creativecommons.org/programs/)
> 6~8월 여름 인턴십 코호트 현재 진행 중. 3개월 프로그램, $7,000 스티펜드 지급. 다음 기수(12월~2월)는 9~10월 신청 오픈 예정.

### [Good First Issue — 초보자 친화 이슈 모음](https://goodfirstissue.dev/)
> goodfirstissue.dev에서 인기 오픈소스 프로젝트의 "good first issue" 레이블 이슈를 언어·카테고리별로 탐색 가능. 별도 가입 없이 바로 사용.

### [For Good First Issue — GitHub 공식 초보자 이슈 플랫폼](https://forgoodfirstissue.github.com/)
> GitHub 공식 운영. 커뮤니티에 기여 가능한 접근하기 쉬운 이슈 큐레이션. 프로젝트 언어 및 태그 필터 지원.

### [AlgoSource — 오픈소스 기회 플랫폼](https://www.algosource.in/)
> 초보자부터 중급자까지 오픈소스 기여 기회를 한곳에서 탐색할 수 있는 플랫폼. 프로젝트별 난이도·기술 스택 필터 제공.
